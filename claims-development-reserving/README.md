# Claims Development and Reserving

## Overview

This project focuses on non-life insurance claims reserving, with the objective of estimating outstanding claims and comparing traditional and machine learning approaches.

The analysis develops and validates both the Chain-Ladder method and a Random Forest model, including inflation adjustment, IBNR estimation and back-testing.

## Methodology

- Claims development analysis
- Inflation adjustment
- Chain-Ladder reserving
- Random Forest model
- IBNR estimation
- Back-testing and model validation
- Credibility-based combination of the two approaches
